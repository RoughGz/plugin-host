Plugin Bridge

Paste a plugin URL (a .sky bundle or plugin.js link) and get an addon URL to paste into Stremio / Nuvio. Nothing is installed on the server — the addon URL carries the plugin link itself.

Repo / folder URL (all plugins inside)

Paste a GitHub repo or folder link — every plugin.js / .sky inside gets its own addon URL. Same as above: nothing stored, everything fetched live.
